# 🚀 Full Stack Portfolio Management System

A modern **Full Stack Portfolio Management System** built with **ASP.NET Core Web API**, **Next.js**, **Angular**, and **SQL Server**. The application enables portfolio management through a secure admin dashboard while providing a fast, responsive portfolio website for visitors.

---

## 📌 Features

### 🌐 Public Portfolio (Next.js)
- Responsive modern UI
- Hero section
- About section
- Skills
- Projects
- Experience
- Education
- Certificates
- Contact Form
- Social Links
- Resume Download

### 🔐 Admin Dashboard (Angular)
- JWT Authentication
- Dashboard Overview
- Manage Projects
- Manage Skills
- Manage Experience
- Manage Education
- Manage Certificates
- Manage Social Links
- Manage Contact Messages
- Profile Management

### ⚙ Backend API (ASP.NET Core)
- RESTful APIs
- JWT Authentication & Authorization
- Repository Pattern
- Service Layer
- Entity Framework Core
- SQL Server
- AutoMapper
- FluentValidation
- Global Exception Handling
- Swagger Documentation

# 🚀 Getting Started

## 1. Clone Repository

```bash
git clone https://github.com/Alokpratihast/Fullstackportfolio.git
```

---

## 2. Backend

```bash
cd AlokPortfolio.Api
```

Restore packages

```bash
dotnet restore
```

Run

```bash
dotnet run
```

Swagger

```
https://localhost:5001/swagger
```

---

## 3. Next.js Frontend

```bash
cd alok-portfolio-web
```

Install packages

```bash
npm install
```

Run

```bash
npm run dev
```

---

## 4. Angular Admin

```bash
cd admin/alokportfolio-admin
```

Install packages

```bash
npm install
```

Run

```bash
ng serve
```
